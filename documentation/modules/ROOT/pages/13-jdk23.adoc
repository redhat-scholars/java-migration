== Duration Until

[.console-input]
[source, java,subs="+macros,+attributes"]
----
final Instant now = Instant.now();
final Instant plusSeconds = now.plusSeconds(50);
System.out.println(now.until(plusSeconds)); // <1>
----
<1> Returns a duration
